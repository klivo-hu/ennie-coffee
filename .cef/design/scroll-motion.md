# Scroll motion

**Instrument:** gsap + ScrollTrigger · https://gsap.com
**Motion level:** 2 of 4

Scroll-driven motion in this project is built from the presets below, through the components
in `components/motion/`. Every one of them runs inside `useGSAP` (so it is reverted on
unmount) and inside a `gsap.matchMedia` branch (so a reader who asked for less motion gets
the finished state, not a slower animation). Content is rendered visible and hidden by
JavaScript, never by CSS — if the script does not run, the page is still readable.

## Presets available at level 2

| Preset             | Effect   | Communicates                                                                       | Reduced motion |
| ------------------ | -------- | ---------------------------------------------------------------------------------- | -------------- |
| `reveal-rise`      | reveal   | Marks the boundary between one section and the next as the reader arrives at it.   | show           |
| `reveal-stagger`   | stagger  | Shows that the items are a set and gives the eye an order to read them in.         | show           |
| `progress-bar`     | progress | Answers "how much is left" — information, which is why it survives reduced motion. | show           |
| `counter-count-up` | counter  | Draws the eye to a figure that is the point of the section, once, and then stops.  | show           |

## Withheld at this level

These effects need a higher motion level. Raise the level deliberately and record why —
do not reach for them by hand.

- `parallax-media` — needs level 3
- `pin-section` — needs level 3
- `scrub-scale` — needs level 3

## Rules

24 rules. `blocker` never ships, `major` clears before completion,
`advisory` may be waived with a reason recorded in `.claude/memory/decisions.md`.

| Rule                                                 | Severity | Refuses                                                                                                                                                                                                                                                                            | Instead                                                                                                                                     |
| ---------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| GS-01 Unregistered ScrollTrigger plugin              | blocker  | Using ScrollTrigger without registering it. The plugin tree-shakes out of a production build when nothing registers it, so the animation works in development and silently does nothing in production.                                                                             | Register once in a single client module (`gsap.registerPlugin(useGSAP, ScrollTrigger)`) and import the effects from there.                  |
| GS-02 GSAP in a Server Component                     | blocker  | A module that touches GSAP or ScrollTrigger without the `"use client"` directive. Both read `window` at import time and throw during the server render.                                                                                                                            | Mark the motion module `"use client"` and keep the boundary at the smallest leaf that needs it (E-023).                                     |
| GS-03 GSAP loaded from a CDN                         | major    | Pulling GSAP from a script tag or CDN URL. The version drifts from the lockfile, the bundle cannot tree-shake it, and it becomes a third-party request the consent gate has to account for.                                                                                        | Install `gsap` and `@gsap/react` as pinned dependencies and import them.                                                                    |
| GS-04 Plugin registered in more than one module      | advisory | Calling `gsap.registerPlugin` in several files. Registration is global and idempotent, so the repetition is not a bug — it is a sign there is no single owner for the motion setup.                                                                                                | Register in one module and import the configured `gsap` from it everywhere else.                                                            |
| GS-05 ScrollTrigger without cleanup                  | blocker  | Creating a tween or ScrollTrigger inside a component without `useGSAP` or `gsap.context`. The instance outlives the unmount, and React Strict Mode mounts twice, so triggers stack, fire twice, and leak listeners.                                                                | Create every animation inside `useGSAP(() => { … }, { scope })`, which reverts tweens, ScrollTriggers, and pin spacing on unmount.          |
| GS-06 Unscoped global selector                       | major    | Animating a bare class selector from inside a component. The selector matches every instance of that class on the page, so a second copy of the component animates the first one.                                                                                                  | Pass a container ref as `useGSAP`'s `scope`, which confines selector text to it.                                                            |
| GS-07 Trigger created per item in a loop             | advisory | One ScrollTrigger per list item. On a long list this is hundreds of independent triggers, each recalculating on every refresh.                                                                                                                                                     | Use `ScrollTrigger.batch` for a set, or one trigger with a staggered timeline.                                                              |
| GS-08 Scroll hijacking                               | blocker  | Taking scrolling away from the user — ScrollSmoother, `ScrollTrigger.normalizeScroll(true)`, a `scrollerProxy` onto a smooth-scroll library, or a swallowed wheel event. It breaks find-in-page, keyboard paging, screen-reader cursors, and every assistive scroll mode (SCR-05). | Animate on native scroll. If the page feels abrupt, fix the composition, not the scrolling.                                                 |
| GS-09 Full-page scroll snap                          | major    | Snapping the scroll position to whole sections. The reader loses the ability to stop between sections, and any section taller than the viewport becomes unreachable in part.                                                                                                       | Let sections scroll freely. Where a snap is genuinely intended, keep it escapable and never on a section taller than the viewport (SCR-06). |
| GS-10 Scrub without an end                           | major    | A scrubbed trigger with no `end`. The range then depends on the element's height at load, so the effect changes speed whenever the content does.                                                                                                                                   | State `end` explicitly so the scroll distance the effect occupies is a decision.                                                            |
| GS-11 Pin without refresh invalidation               | major    | A pinned or scrubbed trigger without `invalidateOnRefresh`. Cached start values survive font loading, image layout, and resize, so the pin releases at the wrong scroll position.                                                                                                  | Set `invalidateOnRefresh: true` on anything pinned or scrubbed.                                                                             |
| GS-25 Framer Motion driving scroll                   | major    | Scroll-driven motion built with Framer Motion's `useScroll`, `useTransform`, or `whileInView`. It works, but it puts a second scroll engine in the page with its own trigger semantics, its own reduced-motion handling, and none of the catalog's guarantees.                     | Use the GSAP runtime for anything the scroll position drives. Framer Motion stays for presence, layout, and gesture (GS-26).                |
| GS-26 GSAP hand-rolling presence or layout animation | advisory | Animating a React subtree in or out by hand, or measuring and tweening a layout change (FLIP), with GSAP. Both are solved problems in Framer Motion, and hand-rolling them means owning the unmount race and the measurement pass yourself.                                        | Use Framer Motion's `AnimatePresence` for exit and its `layout` prop for layout changes. GSAP stays for scroll and timeline choreography.   |
| GS-12 No reduced-motion branch                       | blocker  | Scroll motion built without a `prefers-reduced-motion` branch. Scroll-driven parallax and pinning are the strongest vestibular triggers on the web, and here they are unconditional.                                                                                               | Wrap every scroll animation in `gsap.matchMedia()` and give the reduced branch the finished state, not a slower version of the motion.      |
| GS-13 Content hidden at rest                         | blocker  | Content set to `opacity: 0` in CSS and revealed only by script. If the script fails, the trigger never fires, or JavaScript is off, the content ships and is never seen (IM-030).                                                                                                  | Render content visible and let GSAP set the hidden state from JavaScript (`gsap.set` or `from`), so the page degrades to fully readable.    |
| GS-14 Vestibular parallax range                      | advisory | Parallax displacement beyond roughly a quarter of the element, or a scroll-driven rotation. Large differential movement is the classic vestibular trigger.                                                                                                                         | Keep parallax within ±25% and reserve rotation for content that is about rotation.                                                          |
| GS-15 Focus target inside a pinned region            | major    | A pinned region that holds interactive controls. Focusing a control inside it scrolls the pin, which fights the browser and can strand the focus ring off-screen.                                                                                                                  | Pin presentational regions only, or release the pin while focus is inside it.                                                               |
| GS-17 Over-budget scroll tween                       | major    | A non-scrubbed scroll tween longer than one second. A reveal that outlasts the scroll that triggered it reads as lag, not as motion.                                                                                                                                               | Keep entrance reveals within the duration bands, and let scrub carry long effects.                                                          |
| GS-18 Permanent will-change                          | advisory | A `will-change` left on an element permanently. It holds a compositor layer for the life of the page, which costs memory on exactly the low-end devices it was meant to help.                                                                                                      | Let GSAP manage promotion, or apply `will-change` and remove it when the tween ends.                                                        |
| GS-19 Scroll jank                                    | major    | A scrubbed or pinned effect that drops below 60 FPS while scrolling. Measured, not assumed.                                                                                                                                                                                        | Profile the scroll with the Chrome DevTools MCP (TE-08) and reduce until it holds.                                                          |
| GS-20 Pin-induced layout shift                       | major    | A pin whose spacing shifts the page when it engages or releases, moving content under the reader and costing CLS.                                                                                                                                                                  | Keep default `pinSpacing`, and verify the transition in the browser at each breakpoint.                                                     |
| GS-21 Development markers shipped                    | major    | ScrollTrigger's `markers` left enabled. They render start and end labels over the live page.                                                                                                                                                                                       | Gate markers behind a development check, or delete them when the effect is tuned.                                                           |
| GS-23 Linear ease on a discrete reveal               | advisory | `ease: 'none'` on a tween that is not scrubbed. Linear motion is correct for a scrubbed effect, where the scrollbar is the clock, and mechanical everywhere else.                                                                                                                  | Keep `ease: 'none'` for scrub; use a decelerating ease for entrances.                                                                       |
| GS-24 One identical entrance per section             | advisory | The same fade-and-rise applied to every section in the page, so scrolling becomes a sequence of identical entrances rather than one authored moment (CF-05).                                                                                                                       | Choose the few moments that carry meaning, and let the rest of the page simply be there.                                                    |

## Owed to browser validation

These cannot be decided from source. They are verified in a real browser before completion.

- GS-15 — Focus target inside a pinned region
- GS-19 — Scroll jank
- GS-20 — Pin-induced layout shift
- GS-24 — One identical entrance per section

## Getting started

```bash
npm install
npm run dev
```

## Docker

Two stacks, two files. `docker-compose.dev.yml` is local and must be passed with `-f`;
`docker-compose.yml` is production, and the hosting platform runs it verbatim — so local
conveniences never go in it. See `deploy/DEPLOY.md`.

```bash
docker compose -f docker-compose.dev.yml up --build
```

## Quality gate

`npm run verify` runs the full chain — types, lint, formatting, tests — in the order CEF
reviews them. Run it before every commit and before every deploy.

```bash
npm run verify
```

Design tokens live in `app/globals.css` as CSS custom properties. Components read tokens,
never hard-coded values.
